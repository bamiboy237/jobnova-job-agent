# Private candidate input

`profile.json` and resumes in this directory are private approved input for the general application agent and the provided Lever proof. They are not the application architecture boundary and must not contain Git-tracked real data.

Use an explicit URL:

```text
npm run apply:test -- --url https://jobs.lever.co/ekimetrics/d9d64766-3d42-4ba9-94d4-f74cdaf20065/apply
npm run apply:test:factual -- --url https://jobs.lever.co/ekimetrics/d9d64766-3d42-4ba9-94d4-f74cdaf20065/apply
```
